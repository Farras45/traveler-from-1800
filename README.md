One sentence that explains the modern internet to a traveler from 1800, using only things they could picture: every road, post office, and library in the world woven into one web, where a letter reaches anyone before the tea cools and a book opens before your eyes. The program validates the sentence (one sentence, 1–200 characters) and writes it to `entry.txt`.

## Run it

```sh
node main.ts
```
